# Illustrations - Carnet de Quêtes

## 📁 Fichier requis

Placez l'image du carnet de quêtes dans ce dossier avec le nom exact :

**`carnet-quetes.png`**

## 📋 Instructions

1. Téléchargez l'image du carnet de quêtes
2. Renommez-la en `carnet-quetes.png` (ou `.jpg` si c'est un JPG)
3. Placez-la dans ce dossier : `src/assets/illustrations/carnet-quetes.png`
4. L'image sera automatiquement utilisée dans la page "Ton Campement"

## ✅ Vérification

Une fois l'image ajoutée, elle devrait s'afficher automatiquement au centre de la page "Ton Campement" (Mon Profil).

Si l'image ne s'affiche pas :
- Vérifiez que le nom du fichier est exactement `carnet-quetes.png`
- Vérifiez que le fichier est bien dans `src/assets/illustrations/`
- Redémarrez le serveur de développement (`npm run dev`)
